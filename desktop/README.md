# Clawlinder desktop

From the project root, run `npm install` and then `npm start`.

The desktop app opens at the screen edge. Use `Ctrl+Shift+Space` to show or hide it, and the sidebar pin control to keep it above other windows.

Closing its window hides it to the system tray so importance-based reminders continue. Click the tray icon to reopen; right-click and choose **Quit Clawlinder** to exit. In **Make it yours → Reminders**, test notifications or opt into starting quietly with Windows. Your computer must be awake for reminders.
